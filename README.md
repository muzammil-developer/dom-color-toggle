# JS DOM Color Toggle

A lightweight JavaScript project demonstrating basic DOM manipulation, event handling, and CSS class switching.

## Features

* **DOM Selection:** Targets HTML elements using `document.getElementById()`.
* **Class Manipulation:** Dynamically replaces CSS classes on user interaction.
* **Event Handling:** Uses `onclick` attribute to trigger JavaScript functions.
